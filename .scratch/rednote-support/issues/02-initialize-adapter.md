# 初始化 Rednote 独立平台并保留页面差异调整入口

Type: task
Status: resolved

## Question

如何沿用小红书的现有行为，提供 Rednote 的登录、检查、视频和图文 CLI 入口，同时隔离账号存储，并确保后续真实账号验证可以定位和修改平台差异？

## Comments

- 按用户要求直接实现第一版；真实页面尚未验证的部分必须在文档里明确。

## Answer

新增独立 `sau_commands/rednote.py`、`uploader/rednote_uploader/`、`rednote-upload` Skill 与使用文档，按小红书源码初始化。与小红书隔离命令、cookie 文件、日志及域名配置；本地使用英文 context，托管模式保留 Profile 语言。

实际适配包括：登录在 DOM 就绪后开始等待；有头登录保留短信入口；二维码检测不依赖中文；cookie 前置验证域名；检查路径按调用时的配置构建；发布结果只有留在创作域才可成功；干跑输出明确标记未发布。

新增测试覆盖路由、账号/域名隔离、英文 context、托管模式、登录保存条件和干跑不点击发布。小红书相关回归 437 项通过（其中一项受沙箱影响的浏览器测试在沙箱外重跑通过）。新增登录回归测试另行记录在账号验证票据。
