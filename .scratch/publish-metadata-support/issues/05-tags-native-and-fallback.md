# 各平台的标签写到哪里，什么结果算设置成功？

Type: grilling
Label: wayfinder:grilling
Status: resolved

## Question

十三条媒体发布命令都接受 `--tags`。小红书、Rednote 和 TikTok 找不到精确话题时可保留普通文本；Instagram 和 Facebook 把标签写进配文；YouTube 写 Studio 关键词，失败时可告警继续。对实体、配文、关键词、超限截断和部分成功应如何验收、报告或中止？保留哪些已有调用行为？

单独判断 Facebook Page 的 Reel 关键词框是否也属于这次需要补齐的 Tags 能力。当前 Reel 把 `--tags` 拼进正文，改变该参数含义会改变已发布内容的配文。[Page Reel 编辑器](../../../uploader/meta_uploader/facebook_page_uploader/main.py) · [YouTube 上传器](../../../uploader/youtube_uploader/main.py)

## Comments

- 2026-11-20，操作者提出统一移除 `--tags`，直接从配文中的 `#话题` 识别标签。待确认这些话题是否也写入后台关键词栏，以及已有命令如何迁移。
- 操作者随后确认，十三条命令直接移除 `--tags`，标签只取自配文里的 `#话题`。YouTube Studio 和 Facebook Page Reel 的独立关键词栏保留页面原值。迁移时，调用方把希望公开的话题写进配文；原来只给 YouTube 后台使用的词由调用方决定是否公开。继续传旧参数应在解析命令时收到报错。

## Answer

2026-11-20，操作者确认以最终公开配文为十三条媒体发布命令唯一的话题来源。直接移除 `--tags`，旧调用在参数解析阶段报错。调用方将希望公开的词写成配文里的 `#话题`。保留作者写的顺序、位置、重复和标点，每处话题只输入一次。

| 发布入口 | 从哪里识别、到哪里验收 |
| --- | --- |
| 小红书、Rednote 视频和图文，TikTok 视频和图片帖 | 在配文原位置优先选同名话题。TikTok 视频的 `--title` 就是配文，图片帖取正文。发布前核对配文，并逐个记录能从页面确认的话题关联。 |
| Instagram、Facebook 个人主页、Facebook Page 的视频和图文 | 核对最终配文全文，包括其中的 `#话题`。Facebook Page Reel 的独立关键词栏保留原值。 |
| YouTube 视频 | 从简介识别话题并核对简介。独立标题保持原文，其中的话题不计入配文结果。Studio 后台关键词栏保留原值。 |

以 `今天喝了 #咖啡，配上 #栗子蛋糕` 为例，逗号留在原位，两个话题分别验收。链接中的 `#片段` 跳过，链接原样保留。

- **同名候选缺失。** 如果「咖啡」已关联而「栗子蛋糕」只保留文字，整句回读完整即可发布。结果逐项列出已确认的关联、保留的文字及原因。若界面只能证明文字存在，按实际可见的证据报告。
- **原文或关联有误。** 如果回读发现吞字、错位、意外追加或选成其他话题，停在发布前，指出有差异的文字或话题。全文回读成功是放行条件。
- **超限。** 超过可关联数量后，其余话题按原位置保留为文字并提示。例如小红书的第 11 个话题仍在配文中。命中整帖无法提交的硬限制时，报错并由作者删改，保留完整原稿。
