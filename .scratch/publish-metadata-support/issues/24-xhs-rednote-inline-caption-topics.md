# 24: 小红书与 Rednote 在配文原位关联话题

Status: ready-for-agent
Blocked by: 21

## What to build

小红书、Rednote 的 `upload-video` 与 `upload-note` 识别原稿里的话题，在四个编辑器的原位置点选同名行，逐词核对实际关联及整句配文。

## Acceptance criteria

- [ ] 四条 `sau` 命令各验普通同名行和同名「新建话题」。在正文锚点读到原词才报告「已关联」。通过 `--no-publish` 核对四个编辑器中点选特殊候选后的同名关联和完整原稿，分别记录网页与 CLI 证据。
- [ ] 正文直接传入和既有文件输入采用同一规则。句中混入重复词、紧邻标点、换行和链接片段。处理编辑器自动添加的空格后，作者原有的空格、标点与关联仍在原位，全文逐字一致。
- [ ] 在受控页面造出仅有近似候选的情况，整词保留在原位并注明「无同名候选」。达到可关联数量上限时注明原因，验证小红书第 11 个话题仍完整可读。全文一致时允许部分话题只保留文字。
- [ ] 选成其他话题、吞字、错位、意外追加或触及整帖硬限制时报告差异或限制并停止，发布点击零次。终端逐项报告和原成功摘要可分别识别。
- [ ] 更新四条命令的配文话题栏，注明每个编辑器的 CLI 接入、样本账号、实际语言和阶段。
