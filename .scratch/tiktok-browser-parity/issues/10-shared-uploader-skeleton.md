# 10 — 抽出共用上传骨架（纯重构）

Status: ready-for-agent
Type: task
Blocked by: 无 — 可立即开始
规格依据: spec.md §5.1、§7.2、§7.4

## What to build

把现有 TikTok 视频上传流程抽成一份共用骨架，视频与后续图文帖只实现各自的钩子。对用户而言，`sau tiktok upload-video` 的输出、退出码和操作顺序与今天完全一致；对后续工单而言，隐私、封面、定时、发布等能力有统一插入点，不需要复制发布循环。

这是纯重构：不新增 CLI 参数，不改变任何可观察行为。

## Acceptance criteria

- [ ] `sau tiktok upload-video` 在不传任何新参数时，操作顺序、stdout 与退出码与重构前一致。
- [ ] 共用骨架按规格 §5.1 的九步顺序执行：进页 → 附媒体 → 填元数据 → 等媒体就绪 → 发布选项 → 封面 → 定时 → 发布 → 读结果。
- [ ] 15 分钟发布预算、登录跳转检查、发布循环、定时步骤、基类定位器选择均只有一份实现。
- [ ] 视频子类只保留视频特有钩子与本地模式分支；图文帖可以直接复用骨架而不复制发布循环。
- [ ] 现有离线套件全绿；除方法改名的调用点外，不修改既有断言。
- [ ] 上传 URL 与既有超时常量集中到常量模块，值保持不变。
- [ ] 本地模式（传 Playwright、不传 session）仍可用且行为不变。
