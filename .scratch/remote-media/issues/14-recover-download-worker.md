# 14: 中断等待与恢复后台下载

Status: ready-for-agent
Blocked by: 12, 13

**What to build:** 调度 App 可随时结束等待，保留可续传的进度。后台进程意外退出后，仍在等待的命令能继续取得所需文件。

规格见[网络素材预下载与上传 CLI 规格](../spec.md)。

## 验收条件

- [ ] 用 `sau media predownload --wait` 请求一组素材，在队列中同时留有传输中和未开始的项。Ctrl-C 使等待命令退出 `130`。直接终止该 CLI 也会撤下仅此请求需要的排队项，停止独占传输，保留完整文件和可用断点。
- [ ] 另一个命令仍在等待同一素材时，终止其中一方后源站继续原传输，另一方可取得完整文件。已接受的后台请求也可独立完成。
- [ ] 有命令等待时终止后台进程，即使没有新的 CLI 调用，等待者也能立即拉起新进程并取得正确文件。无人等待时保留队列和断点，由下一次取材恢复。
- [ ] 用多个 CLI 同时触发恢复。核对源站请求、请求偏移及最终文件摘要，同一份文件始终只有一个活动写入者。
