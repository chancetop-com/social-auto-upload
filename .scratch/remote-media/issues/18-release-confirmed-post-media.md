# 18: 按发布结果清理指定任务目录

Status: ready-for-agent
Blocked by: 17

**What to build:** 平台确认 post 已发布后，由发布命令自动释放指定资源目录 ID 下的全部素材。调用方可依据实际发布结果判断之前取得的本地路径是否仍然有效。

规格见[网络素材预下载与上传 CLI 规格](../spec.md)。

## 验收条件

- [ ] 从 `sau` 预下载 A、B、C，仅用 A、B 发布。在离线平台确认成功后，使该 ID 的旧请求失效，撤销仍在排队或传输的 C，等写入结束，再删除整个目录，自动释放所有完整文件和断点。
- [ ] 等待 C 的预下载命令立即以 `task_cleared`、`items=[]` 及退出码 `1` 结束。后台重启后旧请求不会重建目录。调用方此后显式提交的新请求可以再次使用同一 ID。
- [ ] 在离线平台分别模拟发布失败、中断、发布结果未知及不发布模式。各情形均保留指定目录，结果未知沿用退出码 `9`，不发布模式即使退出 `0` 也保留目录。仅完成预下载也保留目录。
- [ ] 按已有的发布结果接入共享清理行为。核对另一 ID、调用方自有文件以及省略 ID 的临时任务各自遵循其归属和清理规则。
