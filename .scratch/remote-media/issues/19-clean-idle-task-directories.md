# 19: 回收闲置满七天的任务目录

Status: ready-for-agent
Resolution: completed
Blocked by: 15

**What to build:** 调度 App 每天运行一次无参数的 `sau media cleanup`，回收本地已满七天且无人使用的任务目录。

规格见[网络素材预下载与上传 CLI 规格](../spec.md)。

## 验收条件

- [x] 以直属任务目录自身的 `mtime` 计算闲置时间。用临时资源根目录设置两个空闲任务，分别恰满 `7 × 24` 小时和少一秒。运行实际 CLI 后，前者被整体删除，后者保留。
- [x] 预下载或发布开始使用，以及结束使用并保留目录时，刷新该目录的 `mtime`。扫描本身不刷新它。外部 App 的未来排期不延长本地保留期。
- [x] 用本机源站和离线平台分别保持任务排队、传输或发布占用。即使目录时间已满七天，每种任务都保留。无法确认空闲时也跳过。
- [x] 删除前取得该 ID 的独占访问并再次核对占用和时间。让另一条命令在扫描后重新使用目录，验证正在使用或时间已刷新的目录仍存在。
- [x] 只回收 CLI 管理的直属任务目录。重复调用后，其他目录、共享队列数据和根目录外的文件仍可用。

## Comments

在本机复核恰满七天和少一秒的边界、扫描后重新使用、排队和发布占用、后台使用后更新时间、失去等待者以及外部目录保护。见 `tests/test_remote_media_cleanup.py`。
