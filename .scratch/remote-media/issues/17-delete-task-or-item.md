# 17: 按任务或 URL 删除素材

Status: ready-for-agent
Blocked by: 15

**What to build:** 调度 App 可用 `sau media delete --task-id ID [--url URL]` 撤销整个任务，或只移除一项再用原 URL 取得新版。

规格见[网络素材预下载与上传 CLI 规格](../spec.md)。

## 验收条件

- [ ] 省略 `--url` 时删除整个任务目录及其中的完整文件和断点。传入完整 URL（含签名参数）时仅移除该项的文件和断点，保留目录及其他素材。单项删除成功后用原 URL 预下载，取得源站已替换的新内容。
- [ ] 撤下范围内全部排队请求，包括尚未创建文件的项，停止正在进行的传输并等写入者退出后才删除。单项删除时，同 ID 的其他 URL 可继续传输。两种删除都允许其他 ID 继续工作。重启后台进程后已撤销的请求不会重建文件。
- [ ] 整任务删除让等待命令立即退出 `1`，返回 `task_cleared` 和空 `items`。单项删除使等待者在每个对应输入位置得到 `reason="item_deleted"`，其余项继续，最终按输入顺序返回 `status="failed"` 并退出 `1`。
- [ ] 用两个实际 CLI 交错执行发布和删除。从发布等待下载到释放该 ID，删除整个任务或其中任意一项均立即退出 `1`，stderr 写一行原因，队列和文件保持原状。删除先取得独占访问时，同 ID 后到的新请求等删除结束后继续。
- [ ] 成功时静默退出 `0`，包括目标已不存在且没有待撤销请求。缺少 ID、把路径当作 ID 或文件删除失败时退出 `1`，仅向 stderr 写一行原因。核对只在指定直属任务目录内删除，目录外文件和符号链接指向的外部目标仍可读。
