- 调研日期：2026-11-10
- 口径：`Business` = Instagram API with Facebook Login；`Standalone` = Instagram API with Instagram Login。
- 「我们」列：`已做` = 现有 `instagram upload-video/upload-note` 已实现；`未做` = 无代码路径；`部分` = 有机制但未覆盖完整边界。

## 汇总

| 分类 | 数量 | 说明 |
|---|---|---|
| 已做 | 8 | 单图/轮播机制/Reels/配文/封面/格式/拓扑/本地直传 |
| 网页有入口、可实现 | 16 | 含 Stories、alt_text、location、collaborators、user_tags、AI、关评论、选帧、配乐、定时、滤镜、隐藏点赞、Story 贴纸、逐张裁剪、批量、FB 交叉 |
| 需资格/实测 | 9 | feed video、Trial Reels、30/20 限额、商品标签、share_to_feed、audio_name、品牌内容、媒体阈值、配额 |
| 很可能 API-only | 6 | caption add-ons、config_issue、毫秒 thumb_offset、音量混合、配额查询、容器状态机 |

**结论**：按「网页可达」对齐，可补的能力远多于按 API 交集对齐；真正要放弃的只有 6 项 API-only。定时发布是唯一需要切换界面（专业后台）的能力，不是网页端不存在。
