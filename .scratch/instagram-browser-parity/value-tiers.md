# Instagram 内容发布能力 — 价值梯队

- 日期：2026-11-10
- 「价值」= 对发布效果 / 合规 / 运营效率的影响；「成本」= 浏览器自动化的实现复杂度；「门槛」= 账号资格或入口灰度。
- 这是建议排序，不是平台事实；可随账号实测调整。

## P0 — 合规与可信度（建议先做）

| 能力 | 价值 | 成本 | 门槛 | 说明 |
|---|---|---|---|---|
| alt_text（仅图片） | 高 | 低 | 无 | 可访问性/合规；文本框，入口明确 |
| AI 生成标识 | 高 | 低 | 无 | 平台合规；开关 |
| 关闭评论 | 高 | 低 | 无 | 品牌安全；网页发布前一步完成，优于 API 的发布后二次调用 |
| 发布后回读对账 | 高 | 中 | 无 | 不是新能力，是可靠性：标签/配文是否真的带上，必须发布后核对 |

## P1 — 触达与分发（核心增长）

| 能力 | 价值 | 成本 | 门槛 | 说明 |
|---|---|---|---|---|
| location | 高 | 中 | 无 | 本地发现；搜索联想控件，成本在选择器 |
| collaborators（≤3） | 高 | 中 | 对方接受 | 联合触达；搜索 + 邀请语义 |
| user_tags | 中高 | 中 | 无 | 互动/曝光；图上坐标点击 |
| 选帧封面 | 中高 | 低 | 无 | 点击率；已有封面上传，补选帧 |
| share_to_feed / feed video | 中 | 低-中 | 入口待实测 | 分发；Reels 流程内开关 |
| Stories（图/视频） | 高 | 中高 | 入口灰度 | 新触点；独立画布/格式入口 |
| 配乐 / 曲库 | 中高 | 中高 | 无 | Reels 效果；曲库搜索与试听 |
| Trial Reels | 中 | 中 | 入口待实测 | 测试受众；Reels 流程内开关 |

## P2 — 商业与品牌（有资格门槛）

| 能力 | 价值 | 成本 | 门槛 | 说明 |
|---|---|---|---|---|
| product_tags | 高 | 高 | IG Shop + 审核目录 + BM 管理员 | 带货；资格比技术更难 |
| partnership ads label | 高 | 高 | 品牌授权 | 品牌合作；资格门槛 |
| caption add-ons（投票/评论提示） | 中 | 高/不可行 | Facebook Login 专属 | 很可能 API-only，网页无创建侧入口 |

## P2 — 运营效率（需切界面）

| 能力 | 价值 | 成本 | 门槛 | 说明 |
|---|---|---|---|---|
| 定时发布 | 高 | 高 | 专业后台资格/灰度 | 不在主 composer；Scheduled content / 批量排期（≤45） |
| 批量上传 | 高 | 高 | 同上 | 规模化运营；与定时共用后台 |

## P3 — 体验增强（低优先）

| 能力 | 价值 | 成本 | 说明 |
|---|---|---|---|
| 滤镜 | 中 | 低-中 | API 无；网页独有 |
| 隐藏点赞/播放数 | 中 | 低 | API 无；网页独有 |
| Story 贴纸/文字/画笔 | 中 | 中高 | API 无；Story 画布能力 |
| 轮播逐张裁剪 | 中 | 中 | API 全部按首图裁切；网页可能逐张 |
| FB 交叉发布 | 中 | 低 | API 无；网页独有 |

## 不纳入（API-only 或无网页等价）

| 能力 | 原因 |
|---|---|
| 毫秒级 thumb_offset | 网页只有选帧，语义不等价 |
| audio_configuration 音量混合 | 网页音量控制范围未知 |
| content_publishing_limit 查询 | 网页无配额查询 |
| 容器状态机 / 24h 过期 / 400 容器 | 纯 API 概念 |
| config_issue 结构化回执 | 网页无字段；用「发布后回读对账」替代（已列 P0） |

## 建议的四个子集

### 子集 A — 合规 MVP（P0）
alt_text、AI 标识、关评论、发布后回读对账。
**特点**：4 项、成本低、无资格门槛，直接提升合规与结果可信度。

### 子集 B — 触达标准（P0 + P1 核心）
MVP + location、collaborators、user_tags、选帧封面、share_to_feed（若实测有入口）。
**特点**：覆盖“被发现 + 被标记 + 封面质量”，是大多数账号的日常刚需。

### 子集 C — 内容扩展（P0 + P1 全部）
标准 + Stories、配乐、Trial Reels（若实测有入口）。
**特点**：增加媒体类型与音频能力，工作量明显上升。

### 子集 D — 运营完整（P0 + P1 + P2 运营）
内容扩展 + 定时发布、批量上传。
**特点**：需要切到专业后台，是独立工程；适合规模化运营。

### 全量网页可达
D + 商业/品牌（product_tags、partnership ads）+ 体验增强（滤镜、隐藏点赞、Story 贴纸、逐张裁剪、FB 交叉）。
**特点**：最接近“尽量对齐”，但资格门槛与维护成本最高。
