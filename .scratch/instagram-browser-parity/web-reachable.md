# 网页端（instagram.com）可以做的内容发布能力

- 日期：2026-11-10
- 口径：只列**网页端存在入口或可表达**的能力；API-only 项单列在最后，不计入。
- 状态：`✅ 已做` = 现有代码已实现；`🟡 未做·入口明确` = 有前端/文档证据，尚未接入；`⚪ 未做·待实测` = 入口存在与否需真实账号确认。

## 1. 媒体类型

| 能力 | 状态 | 入口/阶段 | 说明 |
|---|---|---|---|
| 单图 | ✅ 已做 | 创建弹窗 → 选素材 → 裁剪 → 配文 → 分享 | `upload-note` |
| 轮播（2–20） | ✅ 已做（部分） | 同上，多选 | 只实测 2 张；3/10/20/21 张未测 |
| Reels | ✅ 已做 | 选视频 → 裁剪 → 编辑（封面）→ 配文 → 分享 | 视频固定走 Reels |
| Stories（图/视频） | 🟡 未做·入口明确 | 创建弹窗格式选择 → Story 画布 | 唯一能新增的媒体类型 |
| Feed video / share_to_feed | ⚪ 未做·待实测 | Reels 配文页/高级设置 | 是否有「同时分享到 Feed」开关 |
| Trial Reels | ⚪ 未做·待实测 | Reels 配文页/高级设置 | 是否有 Trial 开关 |

## 2. 配文与文本

| 能力 | 状态 | 入口/阶段 | 说明 |
|---|---|---|---|
| 配文 ≤2200 | ✅ 已做 | 配文页 Lexical 编辑器 | 标题+正文+标签合并 |
| 30 hashtag / 20 @ | ⚪ 未做·待实测 | 配文页 | 网页无客户端计数器，服务端判定 |
| 配文内链接 | ⚪ 未做·待实测 | 配文页 | API 文档未明确；网页可输入，是否可点击需测 |

## 3. 发布元数据

| 能力 | 状态 | 入口/阶段 | 说明 |
|---|---|---|---|
| alt_text（仅图片，≤1000） | 🟡 未做·入口明确 | 照片编辑 / 更多设置 | 合规/可访问性 |
| location | 🟡 未做·入口明确 | 配文页「添加地点」 | 独立专业号也能用 |
| collaborators（≤3） | 🟡 未做·入口明确 | 配文页「邀请协作者」 | 涉及对方接受 |
| user_tags | 🟡 未做·入口明确 | 配文页/照片编辑「标记用户」 | 需图上坐标 |
| product_tags | ⚪ 未做·待实测 | 配文页「标记商品」 | 需 Shop + 审核目录 + BM 管理员 |
| AI 生成标识 | 🟡 未做·入口明确 | 高级设置 | 控件简单 |
| 关闭评论 | 🟡 未做·入口明确 | 高级设置（发布前） | 优于 API 的发布后二次调用 |
| share_to_feed | ⚪ 未做·待实测 | Reels 配文页/高级设置 | 同 Feed video |
| 选帧封面（thumb_offset 等价） | 🟡 未做·入口明确 | 视频编辑页「封面」→ 从视频选帧 | 网页是帧选择器，非毫秒 |
| 上传封面（cover_url） | ✅ 已做 | 视频编辑页「封面」→ 从电脑上传 | `--thumbnail` |
| 配乐 / 曲库 | 🟡 未做·入口明确 | 视频编辑页「声音」 | 网页曲库更大 |
| audio_name（重命名原声） | ⚪ 未做·待实测 | Reels 音频设置 | 是否有入口 |
| partnership ads label | ⚪ 未做·待实测 | 高级设置「品牌内容/付费合作」 | 需品牌授权 |
| caption add-ons（投票/评论提示） | ⚪ 很可能无入口 | 配文页 | 倾向 API-only |

## 4. 媒体规格

| 能力 | 状态 | 说明 |
|---|---|---|
| 图片格式 PNG/AVIF/HEIC | ✅ 已做（更宽） | HEIC/HEIF 受灰度；API 仅 JPEG |
| 大小/时长/宽高比校验 | 🟡 未做·入口明确 | 网页平台侧校验；代码目前只查后缀 |

## 5. 发布行为

| 能力 | 状态 | 入口/阶段 | 说明 |
|---|---|---|---|
| 立即发布 | ✅ 已做 | 配文页分享 | |
| 本地文件直传 | ✅ 已做 | 选素材 | 不需要公网 URL |
| 发布前关评论 | 🟡 未做·入口明确 | 高级设置 | 同「关闭评论」 |
| 定时发布 | 🟡 未做·入口明确 | **专业后台 Scheduled content / 批量排期（≤45）** | 不在主 composer；受资格灰度 |
| 批量上传（≤45） | 🟡 未做·入口明确 | 专业后台 Bulk upload | 与定时共用后台 |
| 发布后回读对账 | ⚠️ 部分 | 发布后读页面/响应 | 现有只严格比对配文，标签类未对账 |
| 配额/限流 | ⚪ 未做·待实测 | 无可见 UI | 只能撞限流 |

| 能力 | 状态 | 入口 | API |
|---|---|---|---|

| FB 交叉发布 | 🟡 未做·入口明确 | 配文页/高级设置 | ❌ 无参数 |

## 7. 账号与结果

| 能力 | 状态 | 说明 |
|---|---|---|
| 账号拓扑无关 | ✅ 已做 | 网页只认 `ds_user_id`，无 Page 概念 |
| 结果三态（published/processing/submission_unknown） | ✅ 已做 | 退出码 0/1/2/9/10/11 |
| verify / delete | ✅ 已做 | 发布后核验与移至最近删除 |

## 8. 网页不可做 / API-only（不计入）

- 毫秒级 `thumb_offset`
- `audio_configuration` 音量混合
- `content_publishing_limit` 查询
- 容器状态机 / 24h 过期 / 400 容器
- `config_issue` 结构化降级回执（用发布后回读对账替代）
