# Instagram 网页端能力 — 价值 × 常用度排序

- 日期：2026-11-10
- 口径：以“常规账号运营/多帖发布”为视角；价值 = 合规/效果/触达，常用 = 每帖或每周使用频率，成本 = 浏览器自动化实现复杂度（1 低–5 高）。
- 综合分 = 0.5×价值 + 0.35×常用 + 0.15×(6−成本)。分数只用于排序，不是绝对结论。

## 分波次建议

### 第一波 — 先做（排名 1–10）
Stories、定时发布、媒体校验、location、关闭评论、配乐、选帧封面、user_tags、alt_text、AI 标识。

**特点**：覆盖“合规 + 触达 + 运营”三条主线；其中 Stories/定时/配乐成本较高，可并行拆成独立工单。

### 第二波 — 按账号需求（排名 11–20）
collaborators、share_to_feed、滤镜、FB 交叉发布、product_tags、批量上传、配额/限流、Story 贴纸、partnership ads、轮播逐张裁剪。

**特点**：价值仍高，但依赖对方接受、账号资格或入口实测；适合有明确运营场景时再做。

### 第三波 — 延后（排名 21–25）
Trial Reels、隐藏点赞、30/20 限额、配文内链接、audio_name。

**特点**：低频或价值有限；等真实账号实测有入口再决定。

## 备注

- “媒体校验”和“配额/限流”不是 API 功能，而是发布可靠性；它们不影响帖子长什么样，但影响失败率与排障成本。
- Stories 与定时发布排在最前，是因为“价值 × 常用”高，不代表成本低；如果先求快速交付，可先把它们换成第一波里的低成本项（alt_text、AI、关评论、选帧、location、user_tags）。
- 所有“入口待实测”的项，建议先用一个测试号点一遍，再决定是否进规格。
