# 36 — 提交语义：ARM → FIRE → OBSERVE

**What to build:** 把"点一次发布"变成机器可证明的三段：就绪前只观察不点，派发最多一次，派发后只认 URL 判断结果。任何 `1` 都意味着确定没发；任何"可能已发"只能是 `9` 或 `10 + publish_attempted=true`。`--no-publish` 升级为"跑到 ARM 就绪"，于是干跑真的能证明"只差点一下"。

**Blocked by:** 31（预算）、33（发布按钮锚点）、34（点击接口与按下前后判定）、35（分类器与文案）.

**Status:** ready-for-agent

**ARM（唯一就绪谓词，上传完成票复用）**

- [ ] 四个条件全满足才算就绪：发布按钮存在；按 `interactive` 档可用（含 disabled / pointer-events / 落点）；`is-publish != "false"`（缺失视为通过）；`submit-disabled != "true"`（缺失视为通过）
- [ ] 每轮**重新解析**，不缓存 locator；新版存在但禁用时**不回落**旧版
- [ ] 1s 轮询；窗口 `min(60s, 剩余预算)`；用尽 → `1`（确定未发布）
- [ ] ARM 轮内命中登录/验证 → `10`，`publish_attempted=False`
- [ ] 定时发布复用同一元素（只变文案），不按策略换按钮

**FIRE**

- [ ] 先置位 `publish_clicked = True`，再派发
- [ ] 派发前顺序：提交前停顿 → 落点复核 → 人类化点击
- [ ] 同一次运行**恰好一次** `mouse.down`；派发后无论抛什么，**不再触碰按钮**
- [ ] 按下之前任何异常 = 确定未派发；按下之后任何异常 = 可能已派发 → `9`
- [ ] 派发后异常且页面已是登录/验证 → `10` + `publish_attempted=true`

**OBSERVE**

- [ ] 500ms 轮询，窗口 `min(15s, 剩余预算)`
- [ ] 判据只认 URL：path 不含 `/publish/publish` 且分类器为无 → `0`
- [ ] 窗口内落登录/验证页 → `10` + `publish_attempted=true`
- [ ] 15s 到点仍在 `/publish/publish` → `9`；预算先耗尽 → `9`
- [ ] C4 与 URL 判定同一循环；分类命中优先于"仍在页面上 → 9"；命中绝不把 `0` 抬成 `10`
- [ ] **零文案扫描**：限流/拒绝/toast 三张词表为空，不再有扫描调用

**检查点与调用方契约**

- [ ] C3：`--not-before` 等待之后、进 ARM 之前必查，命中 → `10`（未派发）
- [ ] `publish_attempted` 一律现取 `publish_clicked` 变量，不按调用点硬编码
- [ ] 仅当"派发后"检出登录/验证时，退出 `10` 额外向 stderr 打**单独一行** `publish_attempted=true`（固定 token、无前缀、无时间戳）；点击前的 `10` 不打
- [ ] 退出码镜像新增本票各行（`0`/`1`/`9`/`10` 前后两态）

**`--no-publish`（干跑）**

- [ ] 跑到 ARM 就绪 → 打一条日志 → `0`，不进入 FIRE
- [ ] 干跑**跳过** `--not-before` 等待，但**仍执行** C1/C2/C3 与定时回读
- [ ] ARM 未就绪 → `1`（预期信号，不是缺陷）

**测试**

- [ ] 四条件逐个不满足 → 继续等；满足 → 恰好 1 次按下
- [ ] FIRE 抛错 → `9` 且零二次点击；ARM 用尽 → `1`；离开且非登录页 → `0`；15s 未离开 → `9`
- [ ] 断言无 toast 扫描调用、无关键词常量
