# 37 — 会话与 `check`

**What to build:** 一次发布只开一次浏览器、只打开发布页一次；登录态真伪只由那一次观测判定，网络故障不再被当成"登录失效"。`check` 用同一个判据给出四类明确结果，本地检查成功时顺手把 cookie 写回，登录成功后不再起第二个浏览器复核。

**Blocked by:** 32（`attached` 判定）、35（分类器与文案）.

**Status:** ready-for-agent

**发布前预检（只有一条零网络快路）**

- [ ] 本地：账号文件存在 + 会话 cookie 存在 + cookie 未过期（过期时间 ≤0 视为未知、放行）；任一不满足 → `10`，**不启动浏览器**，stderr 给出重新登录命令
- [ ] 托管：无前置
- [ ] 删除发布链路里的两个预检（本地网络探测 + 托管登录探测）；会话真伪只由导航发布页后的分类判定

**`check` 行为契约**

- [ ] 本地：前置失败 → invalid / `10`（不起浏览器）；通过 → 带会话打开上下文 → 导航发布页 → 观测
- [ ] 托管：建上下文 → 导航发布页 → 观测
- [ ] 观测：分类命中 → invalid / `10`，`reason` 走 stderr；分类无且上传入口锚点 `attached`（count ≥ 1）→ valid / `0`（本地原子写回）；分类无且一个锚点都没有 → invalid + "页面结构异常" / `1`；导航 5xx / 超时 / 离开创作域 → `1`（探测失败，不是失效）
- [ ] 结果只有两级，不引入"valid-but-degraded"；stdout 仍是 `valid`/`invalid`
- [ ] 页面用发布页，锚点用 `attached` 档（后台健康检查不因慢加载误判）

**登录链路**

- [ ] 扫码完成判据改为"分类器返回无"，删掉现在并存的另一套 URL 前缀判断与登录框可见判断
- [ ] 删除登录后的第二次浏览器复核：改为**同一 context 内**导航一次发布页跑 `probe_session()`；通过 → 原子写回 → success；未通过 → `1`（不判 `10`，避免扫码循环）
- [ ] 二维码抓取与轮询节奏不动

**cookie 写回**

- [ ] 写回矩阵按**结果码**判定：发布成功 `0` / 干跑走完 / 登录复核通过 / 本地 `check=valid` 写回；`1`/`9`/`10` 不写；托管不读不写
- [ ] 写盘为临时文件 + 原子替换

**测试**

- [ ] 前置三态（有/缺/过期）；`check` 四出口；写回矩阵各一条；登录复核断言只 `new_page` 一次；分类四种 path + `?redirectPath=` 不误判
- [ ] 真机注入：移走账号文件 → `10` 且**无**启动日志；改坏 cookie 一个字符 → 启浏览器 → 分类命中 → `10` 且 stderr **不含** `publish_attempted=true`
