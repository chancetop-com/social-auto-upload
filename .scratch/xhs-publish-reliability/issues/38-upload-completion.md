# 38 — 上传完成闸

**What to build:** 素材没传完就不填元数据。图文逐张派发，每张都以"预览瓦片数量到位 + 该瓦片的进行中遮罩消失"为完成；视频以发布按钮的就绪谓词为完成。任何一次失败立刻整体中止，点击前 `1`。

**Blocked by:** 33（上传入口与"+"瓦片锚点）、36（复用 ARM 谓词）.

**Status:** ready-for-agent

**图文**

- [ ] 逐张派发，不批量；张与张之间 1s，每张 500ms 轮询
- [ ] 首张用唯一的上传入口（count == 1）派发
- [ ] 第 2 张起：点"+"瓦片 → 文件选择器 → 只派发 1 张
- [ ] 完成判据 = 预览瓦片数 ≥ i+1 **且** 第 i 个瓦片的进行中遮罩已消失
- [ ] 派发后 60s（按剩余预算收紧）未到位 → 中止，报"第 k 张 / 共 N 张 + 未点击发布" → `1`
- [ ] 计数到位后复检一次 DOM 静默（500ms / 上限 3s）：仍 ≥N → 进填元数据；>N → warning 继续；<N → 继续等至 60s 窗口耗尽 → 中止
- [ ] **禁止** `inputs[0]` / `.first` 兜底（会把视频 input 当图片 input）；**不重传**、不降级少图

**视频**

- [ ] 完成判据 = ARM 谓词满足；窗口 `min(600s, 剩余预算)`，1s 轮询
- [ ] 失败立即中止，不等窗口：视频失败态（class 恰为 fail）或加载失败文案出现
- [ ] 删除全部关键词扫描、阶段扫描、"标题框出现即放行"
- [ ] 上传入口恒在、失败态下按钮恒禁用 —— 两者都不得当作信号

**两者共同**

- [ ] 上传入口缺失/多义/派发抛错 → 立即中止（不等待）
- [ ] 预算耗尽走预算模块的点击前文案，不自造"处理超时"
- [ ] `--no-publish` 同样过就绪闸，然后再停
- [ ] 失败统一 `1`，不按图文/视频/第几张分叉

**测试与真机**

- [ ] 瓦片计数 + 遮罩消失判完成；失败态 → `1`；静默复检三态；第 2 张走文件选择器；预算耗尽文案
- [ ] 真机：图文 2 张正路、视频正路、假 mp4 注入（失败态 → 点击前 `1`，stderr 不含 `publish_attempted=true`）
