# 39 — 话题插入与回读

**What to build:** 话题是增强项：插不进去就保留纯文本 `#tag` 继续发布，绝不因此失败；但只要插进去，就必须**恰好一个**且名字**完全等于**请求的话题，否则点击前中止。编辑区回读取代整页计数，避免预览镜像造成的"每次都 +2"。

**Blocked by:** 33（候选、编辑区与回读锚点）.

**Status:** ready-for-agent

**候选匹配**

- [ ] 顺序扫描全部渲染候选项（真机热榜排序，精确项可能在第 4 位），读候选项名字
- [ ] 两侧同规则归一化：去前导 `#` → 去首尾空白 → 折叠内部连续空白 → casefold
- [ ] 只点名字**全等**的项；多个全等取最前并打 info；无全等即判"无候选"，不做前缀/包含匹配
- [ ] 候选容器按 `attached` 档，被点项按 `interactive` 档

**就绪与重试**

- [ ] 200ms 轮询，deadline `min(5s, 剩余预算)`，每轮重新扫
- [ ] 就绪条件 = 候选项数 > 0，**不是**容器可见（容器会先以 0 项空壳出现）
- [ ] 最多 3 次点击；退出条件：连续找不到 / 用满 3 次 / deadline 到
- [ ] 循环内不回读；循环后统一回读一次

**回读判据**

- [ ] 作用域 = 正文编辑器根（不查整页）
- [ ] 基线按标签条目固定：该标签第一次点击前取一次，重试不刷新；新增 = 点击后多重集合 − 基线
- [ ] 50ms 轮询，窗口 `min(1s, 剩余预算)`；节点只需 `attached`
- [ ] 从话题数据解析名字；解析失败算"名字未知" → 按插错处理

**出口**

- [ ] 候选未出现或 3 次点击后 0 个新增 → 降级：保留纯文本 `#tag` + 一个空格，warning，不算失败
- [ ] 新增 ≥1 但名字 ≠ 请求 → 中止，`reason=topic-mismatch` → `1`
- [ ] 编辑区内新增 > 1 → 中止，`reason=topic-multi-insert` → `1`
- [ ] 恰好 1 个且名字全等 → 成功
- [ ] 降级时**不按 `Backspace` 清理**；不做输入前复位（真实连续插入无需复位）
- [ ] 失败对象带 `tag`/`observed_names`/`new_nodes`/`attempts`，一律点击前 `1`

**上限口径**

- [ ] 只在校验期一处生效：超过 10 个 → warning 列出被丢弃项并取前 10
- [ ] 删除运行时静默截断；CLI 两处"超过 10 报错"降为同文案 warning（不再是 `1`）

**测试**

- [ ] 全等匹配（1 / 4 / 50 项）；0 项空壳不误判；无候选降级 + 空格；插错中止；2 个新增中止；基线不刷新；预算收紧；正文形态示例（`#旅行 #治愈[话题]#`）
