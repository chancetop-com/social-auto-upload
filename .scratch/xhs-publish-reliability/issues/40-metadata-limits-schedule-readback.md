# 40 — 元数据、越限与定时回读

**What to build:** 不可逆动作之前，表单状态尽量可证：标题超长不再静默截断而是开浏览器前就拒绝；正文越限在点击前拦下；定时开关与时间在两个时点回读，不一致就不点发布，避免"日期被页面回滚却按错误时间发出去"。

**Blocked by:** 33（控件锚点）、34（逐字输入）、39（正文与话题全部输入完之后才检查长度）.

**Status:** ready-for-agent

**标题**

- [ ] 长度口径按平台加权：每个 UTF-16 码元 >127 记 2，否则记 1，加总后除 2 向上取整，上限 20
- [ ] 显式传入超限 → 校验期抛错，浏览器未启动，消息含"当前 X / 上限 20"并注明口径；**不截断**
- [ ] 自动推导标题 → 同口径截到 ≤20 并 warning
- [ ] 删除填充时的静默截断
- [ ] 输入后等待 ≥350ms（轮询至 500ms）再查长度后缀警示节点的**存在性**；存在 → `1`

**正文**

- [ ] 正文 + 话题全部输入完成后单次检查长度错误节点；节点存在即失败（不判可见、不读数值）
- [ ] 计数口径：正文逐字符，上限 1000；话题锚点计入且按 `#name` 计（`#旅行pov[话题]#` → 7）
- [ ] 已知：越限时发布按钮仍可用，点击前检查是唯一闸门

**定时（即时发布完全不进入检查）**

- [ ] C1 点开关后：开关状态为已选中（状态类含选中且不含未选中）+ 时间输入框 `attached`
- [ ] C2 写入后：失焦 → 约 300ms → 单次读输入值；解析后**按分钟**等于请求值；开关同 C1
- [ ] C3 FIRE 前：开关 + 值同 C1/C2，且请求值仍晚于本机当前时间；时点在 ARM 就绪之后、`--not-before` 之后、FIRE 之前
- [ ] 解析比较，不要求字符串全等；读失败/空值/不可解析 = 不一致；**不重试**
- [ ] 失焦只允许 `blur()`；**禁止** Tab / Enter / 点空白区
- [ ] 边界：请求时间须晚于现在 2 小时、不晚于现在 14 天；越界在参数校验期 → `1`（浏览器未启动）；墙上时间语义，带时区偏移的输入忽略偏移、按其自带墙上时间格式化
- [ ] `--no-publish` 同样执行 C1/C2/C3

**其余控件**

- [ ] 原创 `true`：点前读状态；未开则点击 + 确认弹窗（勾选须知 → 声明原创）；任一步失败 → `1`；点后不读
- [ ] 原创 `false`：开着则点一次关；控件缺失视为关；点后不读；失败 warning 继续
- [ ] 原创 `None`：不操作
- [ ] 内容类型声明与视频封面维持现有流程，失败 warning 继续（封面首帧兜底）

**失败语义**

- [ ] 全部发生在点击前 → `1`，`publish_attempted=False`；不产生 `9`，不写回账号文件

**测试**

- [ ] 标题加权（ASCII / CJK / emoji / 组合字符边界）、自动标题截断、2h/14d 边界、带偏移输入、长度警示等待窗口、正文长度错误、C1/C2/C3 五种失败（回滚、迟到重置、时效过期、读失败、不可解析）、干跑同拦、即时发布不进检查
