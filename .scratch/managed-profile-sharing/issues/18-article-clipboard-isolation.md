# 18: 大鱼号、知乎、雪球的文章粘贴隔离

Status: ready-for-agent

Blocked by: None

批次：第二批 · [托管 Profile 默认共享规格](../spec.md)

## What to build

两条文章命令交错粘贴时，各自编辑器收到本次原稿及图片。提交前回读能识别明显错贴，同时允许编辑器正常改写排版。

| 平台 | 本单负责的托管入口 |
| --- | --- |
| 大鱼号、知乎、雪球 | `upload-article` |

## Acceptance criteria

- [ ] 离线逐项运行三个文章发布入口，在共享上下文预置同行草稿。核对各自的编辑器、预览、结果和退出码，以及成功或失败清理后同行仍可继续编辑。
- [ ] 用独立 CLI 进程和 Chromium 双连接交错粘贴不同的正文及可辨认的图片，覆盖图片数量相同但内容不同的情形和知乎逐张粘贴 PNG。回读两边编辑器实际收到的正文与图片。
- [ ] 覆盖同一 Profile，以及不同 Profile 共用同一原生剪贴板的情形。每次写入到本命令编辑器取走期间独占剪贴板，一次粘贴完成后另一个编辑器可立即粘贴；一方等待 `--not-before` 时另一方仍可用剪贴板。
- [ ] 以实际编辑器中的可辨认内容作弱校验。合段、改写空白、HTML、排版或图片地址时可通过；意外空正文、读不到可核对内容或明显错贴时在提交前报错，核对发布点击次数为零。
