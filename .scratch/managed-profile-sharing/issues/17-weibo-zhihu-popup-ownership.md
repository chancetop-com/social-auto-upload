# 17: 微博与知乎的弹窗归属

Status: ready-for-agent

Blocked by: None

批次：第二批 · [托管 Profile 默认共享规格](../spec.md)

## What to build

让微博只接收自己首页打开的视频编辑器，知乎只接收自己发布页打开的详情页。用共享 Chromium 上下文和独立连接复现同行恰好开页的顺序。

| 平台 | 本单负责的托管入口 |
| --- | --- |
| 微博、知乎 | `check`、`upload-video` |

## Acceptance criteria

- [ ] 从两个平台的正式 CLI 入口离线覆盖检查与视频，各自新开登录探针、编辑页并清理已确认归属的页面。成功及失败后同行仍停留在原页，内容可继续编辑。
- [ ] 用本机 Chromium 的两个连接，让微博从自己的首页点击进入编辑器，同行同时新开标签。只接受可追溯到该首页的弹窗；真正弹窗未出现时按现有超时报错，只清理能确认归属的页面。
- [ ] 知乎视频发布后的详情弹窗只从自己的发布页识别。离线让同行弹窗先到，或令详情页丢失，核对本次结果和退出码，已派发的发布点击只发生一次。
