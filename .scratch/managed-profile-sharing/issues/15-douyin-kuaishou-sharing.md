# 15: 抖音和快手的检查、视频与图文

Status: ready-for-agent

Blocked by: 08

批次：第二批 · [托管 Profile 默认共享规格](../spec.md)

## What to build

让抖音与快手的每个托管动作独立使用编辑器和登录探针，任一条命令等待或退出时，同行可以继续自己的发布。

| 平台 | 本单负责的托管入口 |
| --- | --- |
| 抖音、快手 | `check`、`upload-video`、`upload-note` |

## Acceptance criteria

- [ ] 逐项从正式 CLI 离线运行六个入口，在共享上下文预置同行草稿。检查自己的探针如期关闭，视频与图文仅在本命令新开或来源可确认的页面导航、填写和监听结果。
- [ ] 令一条发布命令停在等待阶段，同行先完成或失败。核对释放的是退出者的平台资格，等待者仍在自己的原页，草稿位置、内容和可编辑性均保留。
- [ ] 分别核对成功和失败后的页面清理、退出码及适用的发布结果；提交后结果未知时按既有动作契约报告并核对提交次数。
