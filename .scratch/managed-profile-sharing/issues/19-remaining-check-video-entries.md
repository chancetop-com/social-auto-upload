# 19: 其余视频与登录检查入口

Status: ready-for-agent

Blocked by: 08

批次：第二批 · [托管 Profile 默认共享规格](../spec.md)

## What to build

让剩余的 13 个托管入口与同行共用 Profile，验证探针和视频发布只使用自己的页面，并回归本地模式。

| 平台 | 本单负责的托管入口 |
| --- | --- |
| 视频号、支付宝生活号、虎扑、YouTube、百家号、大鱼号 | `check`、`upload-video` |
| 雪球 | `check` |

## Acceptance criteria

- [ ] 逐项从正式 CLI 运行七个登录检查和六个视频入口。各检查在自己的临时页识别登录态，探针结束后临时页已关闭，同行的页面、导航位置和内容仍在。
- [ ] 为各视频动作预置可编辑的同行草稿，核对本次命令打开、操作和关闭的编辑器、预览及结果核对页。分别在成功与失败清理后验证同行仍可继续编辑。
- [ ] 在离线环境区分提交前失败、已提交、结果未知与登录失效。核对各动作既有的结果格式、退出码、适用的 `publish_attempted=true` 和提交次数，同行结果独立保留。
- [ ] 通过既有本地模式入口回归登录态来源、本地 Profile 生命周期、结果格式和退出码。
