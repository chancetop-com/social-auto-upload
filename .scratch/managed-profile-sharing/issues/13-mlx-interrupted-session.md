# 13: Multilogin X 在启动、停止和进程故障后恢复

Status: ready-for-agent

Blocked by: 11, 12

批次：第一批 · [托管 Profile 默认共享规格](../spec.md)

## What to build

在模拟 MLX Launcher 中重现与 AdsPower 相同的故障，让命令根据当前 Profile 与连接状态恢复，分别保留每个发布任务的结果。

## Acceptance criteria

- [ ] 分别终止一条或全部 CLI，验证退出进程的平台资格释放、仍运行的同行可继续。对一直保持活动和手动重开的 Profile，下一条命令使用当前连接新开页，最后离开时只发一次 Stop。
- [ ] 使 Start 响应丢失，再依次模拟活动且可连接、已确认空闲、仍在启动、状态未知或连接不可用。检查正式 CLI 的诊断与 Launcher 调用次数；只有确认空闲时可重启，结果未知时无补偿 Stop。
- [ ] 在旧会话停止过程中申请已空闲的平台，验证有界等待和超时退出。Stop 失败只告警，保留主操作结果。在 Stop 已结束时按当前活动或空闲状态处理。
- [ ] 检查同行与已落盘的结果、适用的退出码及提交次数。新命令不重新提交旧草稿，也不为被强杀的命令补写结果。
