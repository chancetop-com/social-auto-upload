# 11: AdsPower 在进程中断后恢复

Status: ready-for-agent

Blocked by: 08

批次：第一批 · [托管 Profile 默认共享规格](../spec.md)

## What to build

AdsPower 上的同行在另一进程崩溃后继续工作。下一条 CLI 通过指定 Profile 的当前状态恢复使用，保留已有结果及旧草稿。

## Acceptance criteria

- [ ] 在 Mac 用两个独立 CLI 和可控 provider 强杀其中一条。被杀进程的平台资格释放，另一进程继续编辑并持有自己的平台资格。新命令可在已释放的平台另开页，旧草稿仍留在原页。
- [ ] 强杀全部 CLI 后分别保留原浏览器、从桌面关闭后重开。下一条命令取得指定 Profile 的当前连接，另开页面，最后离开时一次 Stop。无需辨认最初由谁启动。
- [ ] 注入 Start 响应丢失或无可用连接信息。后继命令重新查询，确认已打开且可连接时加入，确认启动已结束且空闲时才重新 Start。仍在启动、状态未知或无法取得当前连接时报告原因并退出。核对无重复 Start、无补偿 Stop。
- [ ] 让新命令在旧会话 Stop 期间到达。申请的平台已空闲时有界等待；确认停止后重新申请，超时或结果仍未知时带原因退出。Stop 失败只告警，保留离开者主操作的退出码与结果。
- [ ] 用可控页面记录实际提交次数，并检查已落盘的结果。被强杀的命令可以缺少结果或退出码，恢复流程不代写结果、不续点旧草稿；若可能已提交，由调用方核对作品后再决定是否重跑。
