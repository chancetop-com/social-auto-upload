# 10: 中断后恢复窗口并保留命令结果

Status: ready-for-agent
Resolution: completed
Blocked by: 09

## What to build

遇到启动回包丢失、CLI 被强杀或旧浏览器进程退出较慢时，下一条命令能够从可确认的窗口开始工作，或说明为何暂时不能继续。每条命令保留自己的主操作结果。

## Acceptance criteria

- [ ] 通过模拟 Local API 中断启动响应，再从独立 CLI 进程申请同一 ID。若能确认已经运行且可连接，从新页加入。若仍无法确认，即使暂时没有调试端口，也报告启动结果未明，保留现场，额外打开和关闭请求均为零。
- [ ] 分别注入连接摘要改变、进程仍在但端口缺失或查询失败。后来者在开页前退出，同行的页面和结果不受影响。
- [ ] 强杀所有 CLI，分别保留原窗口、从桌面重开同一 ID。新命令重新识别当前实例，在新标签页工作。旧草稿没有新增提交，已落盘的结果可供核对。
- [ ] 模拟关闭请求已获回应但进程仍存活。下次冷启动必须同时满足关闭后至少 5 秒和旧进程已退出。超过共享层有界等待时向新命令报告原因，该次打开请求为零。
- [ ] 注入页面清理失败、CDP 断开失败及关闭时的 HTTP 429。诊断为告警，保留主结果、退出码和发布信号。常规用户中断仍退出 `130` 并释放该命令的平台占用，同行可继续。
