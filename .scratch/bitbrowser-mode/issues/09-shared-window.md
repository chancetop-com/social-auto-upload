# 09: 两条命令共享同一窗口并分别退出

Status: ready-for-agent
Blocked by: 07

## What to build

同一操作系统用户可从两个独立 CLI 进程操作同一比特浏览器 Profile。不同平台各用自己的页面，同平台占用时后来者立即得到反馈。首条命令离开后，同行仍能继续编辑。

## Acceptance criteria

- [ ] 从正式 CLI 启动两个不同平台的进程，分别覆盖窗口关闭和桌面预开。冷启动总计一次 `/browser/open`，桌面预开总计零次。通过存活进程、按窗口 ID 查询的调试端口及 CDP `/json/version` 核实实例，并复用唯一现有上下文。
- [ ] 同一提供方与窗口 ID 共用占用记录，核对规范化的 Local API 地址和当前连接地址摘要。资源或实例不一致时，后来者在开页前退出 `1`，既有命令和窗口继续工作。
- [ ] 省略显示模式时能加入模式未知或与本地默认值不同的窗口。显式要求有头或无头时，先核对实例报告的模式，缺失时只接受同一连接的共享记录。匹配可加入，冲突或未知时开页前退出 `1`。
- [ ] 同一 Profile 的同平台检查和发布共用一个名额，后来者开页前退出 `1`。同平台不同 Profile 可并行。大陆版小红书与 Rednote、Facebook 个人与 Facebook Page 分别计数。
- [ ] 两张受控页面分别写入并读回不同标记。首条退出时仅清理自己的页及可归属的子窗口，关闭窗口请求为零。同行能在原页追加并读回标记，桌面预开场景还能读回原标签的标记。
- [ ] 末条命令直接按原窗口 ID 调用一次 `/browser/close`，包括桌面预开的窗口。验收记录指出这一步按 ID 归还窗口，旧命令存活期间桌面若重开同一 ID，末条旧命令可能关闭新窗口。
