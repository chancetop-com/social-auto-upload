# 19: 执行一次性旧资料迁移并删除临时实现

**What to build:** 既有账号可以在明确选定的 Profile 中重新登录，经关闭重开证明当时可恢复后，安全清理对应旧 Cookie 和身份资料；这项作业完成后只保留执行记录，日常命令不留下迁移入口、兼容分支或额外复验。

**Blocked by:** [16：大鱼号接入及匿名公开验证](./16-dayu-persistent-profile.md)；[17：知乎全流程与当次身份接入](./17-zhihu-persistent-profile.md)；[18：雪球全流程与当次身份接入](./18-xueqiu-persistent-profile.md)

**Status:** ready-for-agent

**批次：** 五批接入后的一次性作业

**依据：** [原始规格](../../local-chrome-profile/spec.md)；[实施顺序与共同约束](../README.md)。

- [ ] 执行前落实当次迁移的平台、原始账号别名、实际浏览器种类和已有账号登录条件，逐项确定能安全、唯一匹配的旧资料；仅处理对应旧 Cookie，以及大鱼号、知乎、雪球的对应身份旁文件。路径不明或不唯一时报告故障，不猜测删除目标，不为其他平台获取新账号。
- [ ] 临时迁移编排复用正常 Profile 取得、配置解析和平台登录探测能力，独立于常驻 login/session；不导入 Cookie，不解析旧身份作为新账号约束。旧文件缺失、损坏、属于不同真实账号或仅身份旁文件残留都不阻挡新 Profile 登录。
- [ ] 先在所选 Profile 引导重新登录并取得正向证据，正常关闭后按同目录、同种类、同次启动配置重开，复验正向登录证据并再次正常关闭；完整序列及两次启动间持续持有占用权。
- [ ] 重开复验不自动引导再次登录、不借助旧资料、不比较前后真实账号；两次登录核验及两次关闭都成功才允许删除旧资料，任一关闭失败不能通过清理验收。
- [ ] 仅定向删除已明确匹配的旧资料，不建备份；不触碰其他别名、未迁移平台、托管资料、另一种类 Profile 或历史发布结果。reset-profile 不参与旧资料清理。
- [ ] 任一阶段失败、取消或无法可靠判定时保留尚未删除的文件；删除失败退出 1，列明剩余目标并保留有效新 Profile。部分删除不回滚，迁移阶段重试只处理剩余目标，已不存在视为清理完成，两种浏览器处理同一旧文件也能收敛。
- [ ] 先以合成资料验证旧文件缺失/损坏/不同主体、仅旁文件残留、安全定位、两阶段证据、关闭/取消失败不提前删除、定向删除、部分失败及重试；不把真实账号文件当作破坏性测试夹具。
- [ ] 由实施 Agent 执行已落实账号范围的一次性作业，记录实际目标、两次核验/关闭证据、清理结果、剩余项及具体阻塞；对失败项在本次迁移阶段解决并重试，不以永久待迁移状态或以后 login 自动处理代替收口。
- [ ] 完成一次性作业后，实际删除新建的旧资料定位/存在检测、额外重启复验、清理/重试、临时入口和仅服务迁移的测试代码；不只是关闭开关，也不保留永久迁移工具或停用分支。交付可审查的执行与代码移除记录。
- [ ] 保留正常 Profile 创建、登录探测、持久化复用、生命周期、重建能力和相关回归；用正常命令的外部行为验证旧文件重新出现后不被读取、改写或删除，也不导致普通 login 额外重启。
- [ ] 来源或平台故障不自动清空 Profile，迁移成功只证明当时可恢复，迁移失败不成为发布重试理由；不续跑旧发布任务，不进行真实发布或作品删除。
- [ ] 完成条件同时包括实际迁移结果和临时代码删除；尚未执行或被登录/环境阻塞的目标如实记录，不能以合成测试或关闭兼容开关宣称迁移已经完成。后续 20 的最终验收在本票完成后开始。
